# 核心概念

本部分介绍 OpenCrab 中的核心概念，帮助你理解系统的设计理念和工作原理。

## 概念概览

| 概念 | 说明 |
|------|------|
| [智能体（Agent）](./agent.md) | 具有自主决策能力的 AI 实体，是系统的核心执行单元 |
| [技能（Skills）](./skills.md) | 智能体的内在工作能力，如代码审查、文档写作等 |
| [能力（Capabilities）](./capabilities.md) | 智能体的外在扩展，通过工具或 API 实现 |
| [记忆（Memory）](./memory.md) | 智能体的短期和长期记忆系统 |
| [工具（Tool）](./tool.md) | 智能体的外部扩展功能，如调用 API、访问文件系统等 |
| [工作区（Workspace）](./workspace.md) | 独立的工作环境，包含相关文件和目录 |
| [聊天（Chat）](./chat.md) | 消息和对话系统 |
| [调度（Scheduler）](./scheduler.md) | 定时任务和日程管理系统 |

## 核心设计理念

OpenCrab 围绕"智能体"这一核心概念展开，智能体遵循"感知-思考-行动-学习"的循环：

1. **感知**：从环境中获取信息
2. **思考**：基于感知到的信息进行推理和决策
3. **行动**：执行决策产生的动作
4. **学习**：从行动结果中学习，更新记忆和知识
