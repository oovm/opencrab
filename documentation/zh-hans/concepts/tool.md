# 工具（Tool）

**工具（Tool）**是智能体的外部扩展功能，如调用 API、访问文件系统、执行命令等。工具是智能体"能调用什么"的体现。

## 核心概念

工具是智能体与外部世界交互的桥梁，通过工具，智能体可以：

- 访问文件系统
- 执行系统命令
- 调用外部 API
- 与其他服务交互

## 工具与技能的关系

| 概念 | 说明 | 定位 |
|------|------|------|
| **技能（Skill）** | 智能体的内在能力，决定智能体的专业领域 | "会做什么" |
| **工具（Tool）** | 智能体的外在扩展，决定智能体的操作边界 | "能调用什么" |

技能可以调用工具来完成复杂任务。例如，一个"代码审查"的技能可能会调用"文件读取"工具来获取代码文件，然后调用"LLM"工具来进行审查。

## 设计理念

工具系统的设计遵循"安全可控"原则：

1. **权限控制**：每个工具都有明确的权限要求，智能体只能在授权范围内调用
2. **参数校验**：工具调用前进行参数校验，确保调用安全
3. **结果封装**：工具执行结果统一封装，包含成功/失败状态和错误信息
4. **可审计**：所有工具调用都有日志记录，便于审计和调试

## 内置工具

系统提供一组内置工具，覆盖常见场景：

### 文件工具
- **读取文件**：读取指定文件的内容
- **写入文件**：向指定文件写入内容
- **列出目录**：列出指定目录的内容
- **创建目录**：创建新目录
- **删除文件**：删除指定文件或目录
- **文件信息**：获取文件的元数据

### Shell 工具
- **执行命令**：执行 Shell 命令
- **命令输出**：获取命令执行的输出
- **命令状态**：获取命令执行的状态

### 记忆工具
- **保存记忆**：保存一条记忆
- **检索记忆**：检索相关的记忆
- **删除记忆**：删除指定的记忆
- **列出记忆**：列出所有记忆

### 时间工具
- **获取当前时间**：获取当前的日期和时间
- **时间格式化**：格式化时间字符串
- **时间计算**：进行时间计算

### HTTP 工具
- **发送 GET 请求**：发送 HTTP GET 请求
- **发送 POST 请求**：发送 HTTP POST 请求
- **发送 PUT 请求**：发送 HTTP PUT 请求
- **发送 DELETE 请求**：发送 HTTP DELETE 请求

### MCP 工具
- **MCP 协议支持**：支持 MCP（Model Context Protocol）协议
- **MCP 服务发现**：发现可用的 MCP 服务
- **MCP 工具调用**：调用 MCP 服务提供的工具

## 工具生命周期

工具从注册到执行经历以下阶段：

1. **注册**：工具被注册到工具管理器
2. **发现**：智能体根据任务需求发现相关工具
3. **参数校验**：校验调用参数的合法性
4. **权限检查**：检查智能体是否有调用权限
5. **执行**：执行工具的核心逻辑
6. **结果返回**：返回执行结果
7. **日志记录**：记录工具调用日志

## 自定义工具

系统支持自定义工具的开发和注册：

- **工具定义**：定义工具的名称、描述、参数、返回值
- **工具实现**：实现工具的核心逻辑
- **工具注册**：将工具注册到工具管理器
- **权限配置**：配置工具的权限要求
