# 技术选型

## 概述

本文档记录 OpenCrab 系统的技术选型决策，包括编程语言、框架、数据库、通信协议等。

## 编程语言与运行时

| 类别 | 技术选型 | 说明 |
|------|---------|------|
| **后端语言** | Rust (2024 Edition) | 内存安全、高性能、零成本抽象 |
| **异步运行时** | Tokio | 全功能异步运行时，性能优异 |
| **前端框架** | Vue 3 + TypeScript | 渐进式框架，类型安全 |
| **GUI 框架** | Tauri | 轻量级、安全、高性能桌面应用 |

## Web 框架与中间件

| 类别 | 技术选型 | 参考 | 说明 |
|------|---------|------|------|
| **Web 框架** | axum | wae-https | 基于 tokio 的模块化 Web 框架 |
| **HTTP 客户端** | reqwest | wae-request | 异步 HTTP 客户端 |
| **中间件** | tower-http | wae-https | 常用 HTTP 中间件集合 |
| **WebSocket** | tokio-tungstenite | wae-websocket | WebSocket 实现 |

## 技术选型原则

1. **开源优先**：优先选择成熟的开源技术
2. **标准化**：遵循行业标准和最佳实践
3. **可扩展**：选择支持水平扩展的技术
4. **安全性**：优先考虑安全性和隐私保护
5. **性能**：确保技术选型满足性能要求
6. **参考 wae**：基础设施层参考 wae 的技术选型
7. **参考 ironclaw**：核心层吸收 ironclaw 的优秀技术选型

## 节点间通信

### 发现机制

系统采用多层节点发现机制：

| 发现方式 | 技术选型 | 用途 |
|---------|---------|------|
| **局域网发现** | mDNS/Bonjour | 自动发现本地网络节点 |
| **云端发现** | 云端目录服务 | 发现远程节点 |
| **手动连接** | 直接地址输入 | 手动指定节点连接 |

### 通信协议

| 协议类型 | 技术选型 | 用途 |
|---------|---------|------|
| **实时通信** | WebSocket | 双向实时通信 |
| **服务调用** | gRPC | 高效的服务间调用 |
| **文件同步** | rsync 或类似协议 | 增量文件同步 |

### 安全通信

| 安全机制 | 技术选型 | 说明 |
|---------|---------|------|
| **传输加密** | TLS 1.3 | 所有通信加密 |
| **节点认证** | 节点证书 | 双向认证 |
| **数据加密** | 端到端加密 | 敏感数据端到端加密 |

### 节点类型支持

系统支持以下工作节点类型：

| 状态 | 描述 |
|------|------|
