# 生态系统总览

本文档描述 OpenClaw 生态系统的整体架构，说明各项目之间的关系和定位。

## 概述

OpenClaw（又称"龙虾"）是一个开源的 AI Agent 框架，定位为可以被指挥工作的 AI 智能体。整个生态系统围绕"让 AI 自动执行任务"这一核心理念构建，提供从协议层到应用层的完整解决方案。

### 生态系统目标

1. **开放性**：开源、开放协议，支持去中心化互联
2. **可扩展**：模块化设计，支持插件和扩展
3. **易用性**：提供多种客户端形态，满足不同场景需求
4. **安全性**：零信任架构，端到端加密

---

## 核心概念

### OpenClaw 产品形态

OpenClaw 是一种 AI Agent 系统，帮助用户管理 AI 模型，并让 AI 自动执行任务。简单理解：OpenClaw 就像一个 AI 管家，它可以：

- **调用 AI 模型**：支持多种 LLM 提供商
- **分配任务**：智能调度和编排
- **自动执行流程**：工具调用、工作流执行

## 项目关系详解

### 协议层：Skynet

**定位**：去中心化互联协议

Skynet 是整个生态系统的通信基础设施，定义节点间的通信标准。

**核心职责**：

- 提供标准化的通信协议
- 支持去中心化网络互联
- 定义数据格式和接口规范
- 提供身份认证和安全机制

**主要模块**：

| 模块 | 功能 |
|------|------|
| `skynet-types` | 基础类型定义 |
| `skynet-auth` | 认证协议 |
| `skynet-chat` | 聊天协议 |
| `skynet-gateway` | 网关协议 |
| `skynet-memory` | 记忆协议 |
| `skynet-service` | 服务协议 |
| `skynet-bridge` | 桥接协议 |
| `skynet-notification` | 通知协议 |

---

### 运行时层：wae

**定位**：以代数效应为主的服务器运行时

wae 提供模块化的后端基础设施，是构建智能体应用的基础运行时。

**核心特性**：

- **代数效应**：声明式依赖注入，简化依赖管理
- **模块化设计**：每个功能独立成 crate，可单独使用
- **多后端支持**：支持多种数据库、存储、AI 服务商
- **统一错误处理**：统一的错误类型和处理方式

**主要模块**：

| 模块 | 功能 |
|------|------|
| `wae-types` | 基础类型定义 |
| `wae-https` | HTTP/HTTPS 服务 |
| `wae-ai` | AI 服务抽象 |
| `wae-authentication` | 认证服务 |
| `wae-storage` | 存储抽象 |
| `wae-websocket` | WebSocket 服务 |
| `wae-database` | 数据库 ORM |
| `wae-scheduler` | 任务调度 |
| `wae-resilience` | 弹性容错 |

**设计原则**：

1. **抽象优先**：先定义 trait，再提供实现
2. **多后端支持**：支持多种实现，易于切换
3. **零抽象开销**：在性能关键路径上保持零抽象
4. **类型安全**：前后端类型一一对应

---

### 核心层：crab-* 模块

**定位**：智能体核心功能模块

crab-* 模块是所有应用共享的核心功能层，提供智能体管理、技能系统、记忆系统等核心能力。

**主要模块**：

| 模块 | 功能 |
|------|------|
| `crab-agent` | 智能体管理 |
| `crab-skill` | 技能系统 |
| `crab-memory` | 记忆系统 |
| `crab-chat` | 聊天系统 |
| `crab-tool` | 工具系统 |
| `crab-scheduler` | 调度系统 |
| `crab-workspace` | 工作区管理 |
| `crab-types` | 基础类型定义 |

**设计原则**：

1. **模块化**：每个功能独立成模块，可单独使用
2. **可复用**：所有应用共享同一套核心模块
3. **可扩展**：支持插件和扩展机制
4. **类型安全**：统一的类型定义和接口规范

---

### 应用层：oh-my-* 应用

**定位**：面向不同场景的客户端应用

所有 oh-my-* 应用都是同级关系，共享 crab-* 核心模块，采用前后端一对多架构。

#### oh-my-crab（个人形态）

**定位**：个人 AI 助手应用

**特点**：

- 个人 AI 助手界面
- 单用户场景优化
- 本地化部署支持
- 轻量级架构

**适用场景**：

- 个人日常使用
- 本地开发测试
- 隐私敏感场景

#### oh-my-empire（帝国形态）

**定位**：企业级 AI 员工管理平台

**特点**：

- AI 员工管理：将 AI 智能体作为企业员工
- 角色化 AI 助手：客户服务、财务、营销、行政助理、法律等
- 知识管理系统
- 军团（Legion）协作

**适用场景**：

- 企业级部署
- 多部门协作
- 商业化运营

#### oh-my-waifu（角色形态）

**定位**：AI 角色聊天应用

**特点**：

- AI 角色聊天界面
- 角色交互和养成
- 个性化体验
- 情感陪伴

**适用场景**：

- 娱乐社交
- 角色扮演
- 个性化互动

#### oh-my-planet（星球形态）

**定位**：社区型 AI 协作平台

**特点**：

- 社区协作
- 知识共享
- 多智能体协作
- 去中心化治理

**适用场景**：

- 开源社区
- 知识社区
- 协作网络

#### oh-my-home（家庭形态）

**定位**：家庭 AI 管理平台

**特点**：

- 家庭成员管理
- 家庭任务协作
- 智能家居集成
- 家庭知识库

**适用场景**：

- 家庭日常管理
- 家庭教育辅助
- 智能家居控制

## 前后端架构模式

### 一对多模式

所有 oh-my-* 应用采用统一的前后端一对多架构模式。

```
┌─────────────────────────────────────────────────────────────┐
│                      前端应用（多个）                          │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐        │
│  │ oh-my-crab  │  │oh-my-empire │  │ oh-my-waifu │        │
│  │  (个人形态)  │  │  (帝国形态)  │  │  (角色形态)  │        │
│  └─────────────┘  └─────────────┘  └─────────────┘        │
│  ┌─────────────┐  ┌─────────────┐                          │
│  │oh-my-planet │  │ oh-my-home  │                          │
│  │  (星球形态)  │  │  (家庭形态)  │                          │
│  └─────────────┘  └─────────────┘                          │
└─────────────────────────────────────────────────────────────┘
                           ↓
                    共享 crab-client
                           ↓
┌─────────────────────────────────────────────────────────────┐
│                      后端服务（一个）                          │
│  ┌─────────────────────────────────────────────────────┐   │
│  │                    crab-* 核心模块                    │   │
│  │  crab-agent | crab-skill | crab-memory | crab-chat  │   │
│  │  crab-tool  | crab-sched | crab-work   | crab-types │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

**特点**：

- 一个后端服务支持多个前端客户端
- 所有应用共享 crab-* 核心模块
- 支持多账号切换
- 模块化设计，易于扩展

## 总结

OpenClaw 生态系统采用清晰的分层架构：

1. **协议层（Skynet）**：提供去中心化互联协议，是所有项目的基础
2. **运行时层（wae）**：提供模块化的服务器运行时，简化应用开发
3. **核心层（crab-*）**：提供智能体核心功能模块，所有应用共享
4. **应用层（oh-my-*）**：面向不同场景的客户端应用

各应用之间的关系：

- **oh-my-crab**：个人形态应用，适合个人日常使用
- **oh-my-empire**：帝国形态应用，适合企业级部署
- **oh-my-waifu**：角色形态应用，适合娱乐社交场景
- **oh-my-planet**：星球形态应用，适合社区协作
- **oh-my-home**：家庭形态应用，适合家庭管理

所有应用都是同级关系，共享 crab-* 核心模块，采用前后端一对多架构。

这种架构设计确保了：

- **可扩展性**：新应用可以基于现有基础设施快速构建
- **互操作性**：所有应用通过 Skynet 协议互联
- **灵活性**：可以根据需求选择不同的应用形态
- **可维护性**：清晰的分层和模块化设计
- **复用性**：核心模块在所有应用间共享
