## 五层架构

OpenCrab 采用清晰的五层架构设计，每层都有明确的职责和边界。**基础设施层现已直接依赖 WAE 项目**，不再维护独立的 crab-* 基础设施模块。

### 各层职责说明

#### 1. 前端应用层（oh-my-* / on-my-* 系列）

前端应用层是用户直接交互的界面，所有应用都是同级关系，共享 crab-* 核心模块。

**主要应用：**
- `oh-my-crab` - GUI 图形界面客户端（Tauri + Vue）
- `oh-my-empire` - 帝国形态前端
- `oh-my-waifu` - 角色形态前端
- `oh-my-planet` - 星球形态前端
- `oh-my-home` - 家庭形态前端
- `on-my-claw` - CLI 命令行客户端

**特点：**
- 所有应用同级，共享 crab-* 核心模块
- 前后端一对多架构（类似个人微信）
- 支持多账号切换
- 共享 `crab-client` 客户端库

#### 2. 服务端层（opencrab）

服务端层是系统的服务提供者，提供单机智能体节点服务。

**主要服务端：**
- `opencrab` - 单机智能体节点（前后端一对多）

**特点：**
- 单机智能体节点，参考 ironclaw 重构
- 共享核心层和基础设施层
- 基于 Skynet 协议，可互联互通

#### 3. 核心层（crab-* 核心业务模块）

核心层是系统的核心业务逻辑层，包含多个专门的功能模块。详见 [core-layer.md](core-layer.md)。

**主要模块：**
- `crab-agent` - 智能体管理
- `crab-skill` - 技能管理
- `crab-memory` - 记忆系统
- `crab-chat` - 聊天系统
- `crab-tool` - 工具管理
- `crab-scheduler` - 调度系统
- `crab-workspace` - 工作区管理
- `crab-types` - 核心类型定义

#### 4. 基础设施层（WAE 项目）

基础设施层提供系统运行所需的基础服务支撑。OpenCrab 现已直接依赖 **WAE 项目**的基础设施模块，不再维护独立的 crab-* 基础设施模块。详见 [infrastructure.md](infrastructure.md)。

**主要模块（来自 WAE）：**
- `wae-config` - 配置管理
- `wae-database` - 数据库服务
- `wae-cache` - 缓存系统
- `wae-https` - HTTP 服务
- `wae-effect` - 代数效应依赖注入
- `wae-queue` - 队列系统
- `wae-event` - 事件系统
- `wae-storage` - 存储抽象
- `wae-types` - 基础类型定义

#### 5. 协议层（Skynet 协议）

协议层提供底层的通信和数据交互协议，是整个系统的基础设施。详见 [Skynet 协议](../skynet/index.md)。

**主要协议：**
- `skynet-types` - 基础类型定义
- `skynet-auth` - 认证协议
- `skynet-chat` - 聊天协议
- `skynet-gateway` - 网关协议
- `skynet-memory` - 存储协议
- `skynet-service` - 服务协议
- `skynet-bridge` - 桥接协议
- `skynet-notification` - 通知协议
- `skynet-persistence` - 持久化协议

## 与 Skynet 的关系

Skynet 协议构成了 OpenCrab 系统的基础设施层（协议层）。本目录描述的是 OpenCrab 的**设计理念和架构原则**，而 [Skynet 协议](../skynet/index.md) 是这些设计理念的**具体技术实现**。

### 设计理念与技术实现对应

| 设计理念 | Skynet 实现 |
|---------|-----------|
| 零信任架构 | 节点身份验证、端到端加密 |
| 去中心化 | 对等网络、主网-子网两级结构 |
| 可验证计算 | 数字签名、多节点交叉验证 |
| 数据主权 | 端到端加密、用户控制密钥 |

详见 [Skynet 协议](../skynet/index.md) 了解具体技术实现，详见 [架构总设计](master-plan.md) 了解 OpenCrab 的整体架构。
