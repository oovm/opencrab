# 核心特性

OpenCrab 提供了丰富的核心功能，让您的 AI 智能体更加强大和灵活。

## 智能代理系统

- **消息路由**：智能处理和路由用户消息
- **任务执行**：自动执行各种任务和工作流
- **多账号管理**：支持多个智能体账号切换
- **上下文管理**：智能维护对话上下文

## 多通道支持

- **HTTP API**：提供 RESTful API 接口
- **WebSocket**：实时双向通信
- **CLI**：命令行工具支持
- **多种接入方式**：满足不同场景需求

## LLM 集成

- **统一接口**：提供统一的 LLM 提供商接口
- **多模型支持**：支持多种 AI 模型
- **灵活切换**：轻松切换不同的模型提供商
- **成本优化**：智能选择最适合的模型

## 工具系统

- **内置工具**：提供丰富的内置工具
- **MCP 支持**：兼容 Model Context Protocol
- **WASM 工具**：支持 WebAssembly 工具扩展
- **可扩展架构**：轻松添加自定义工具

## 技能系统

- **技能定义**：灵活定义智能体技能
- **技能组合**：组合多个技能完成复杂任务
- **技能学习**：支持技能扩展和学习
- **技能市场**：共享和发现新技能

## 记忆系统

- **对话记忆**：保存对话历史
- **长期记忆**：持久化重要信息
- **向量检索**：语义搜索和检索
- **上下文关联**：智能关联相关记忆

## 调度系统

- **任务调度**：定时和事件触发任务
- **工作流编排**：编排复杂工作流
- **优先级管理**：智能管理任务优先级
- **容错处理**：可靠的错误恢复机制

## 持久化

- **多数据库支持**：支持 SQLite、libSQL、PostgreSQL 等
- **灵活存储**：支持本地文件系统和云存储
- **数据安全**：本地存储，保护隐私
- **备份恢复**：轻松备份和恢复数据

## 配置管理

- **灵活配置**：支持多种配置源
- **环境变量**：支持环境变量配置
- **热重载**：支持配置热更新
- **验证机制**：配置验证和校验

## 模块化架构

- **高内聚低耦合**：每个模块职责清晰
- **独立测试**：模块可单独测试
- **可插拔**：模块可插拔替换
- **易于扩展**：轻松添加新功能

## 前后端一对多架构

- **一个后端**：统一的后端服务
- **多个前端**：支持多种前端应用
- **账号切换**：类似个人微信的体验
- **统一体验**：一致的用户体验

- **标准化通信**：标准化的节点间通信
