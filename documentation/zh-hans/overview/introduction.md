# 项目介绍

## 什么是 OpenCrab？

OpenCrab 是一个单机智能体节点系统，是 OpenClaw 生态系统的基础节点实现。它为用户提供本地化的 AI 智能体服务，让您可以在自己的设备上运行 AI 助手。

简单来说，OpenCrab 就像您的个人 AI 管家，它可以：
- 调用各种 AI 模型
- 自动执行任务
- 管理您的对话和记忆
- 扩展各种技能和工具

## 定位

OpenCrab 的核心定位是**单机智能体节点**，特点包括：

- **个人化**：专为个人用户设计，数据本地存储
- **轻量级**：适合在普通设备上运行
- **可扩展**：支持插件和扩展机制
- **互联互通**：实现 Skynet 协议，支持与其他节点互联

## 设计理念

OpenCrab 遵循以下核心设计理念：

### 1. 模块化设计
每个功能模块独立成 crate，可单独测试和复用。这种设计使得系统具有极高的灵活性和可维护性。

### 2. 分层架构
采用清晰的四层架构：
- **协议层**：提供标准化的通信协议
- **基础设施层**：提供通用的基础设施服务
- **核心层**：实现智能体核心逻辑
- **应用层**：面向不同场景的客户端应用

### 3. Capability 模式
通过 trait 定义能力，每个能力独立声明，系统通过实现多个 Capability 来声明支持的功能。

### 4. 依赖注入
采用代数效应风格的依赖管理，通过单一的 Effectful 参数统一管理所有依赖。

### 5. 协议优先
协议层独立设计，支持多种应用形态，确保系统的互联互通。

## 与 OpenClaw 的关系

OpenCrab 是 OpenClaw 生态系统的基础节点实现。OpenClaw 是整个生态系统的框架，而 OpenCrab 是其中的单机智能体节点实现。

## 为什么选择 OpenCrab？

- **数据隐私**：所有数据存储在本地，保护您的隐私
- **灵活性高**：模块化设计，可根据需求定制
- **易于扩展**：支持插件和扩展机制
- **社区驱动**：开源项目，社区共同维护和发展
