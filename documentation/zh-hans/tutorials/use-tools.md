# 使用工具

本教程将介绍如何使用 OpenCrab 的内置工具和自定义工具，让智能体能够与外部世界交互。

## 工具概述

**工具（Tool）**是智能体的外部扩展功能，是智能体"能调用什么"的体现。通过工具，智能体可以访问文件系统、执行命令、调用 API 等。

工具系统的设计遵循"安全可控"原则：
- 权限控制：每个工具都有明确的权限要求
- 参数校验：工具调用前进行参数校验
- 结果封装：统一封装执行结果
- 可审计：所有工具调用都有日志记录

## 为智能体启用工具

### 通过界面配置

1. 打开 OpenCrab 界面
2. 选择要配置的智能体
3. 进入"工具"或"能力"设置页面
4. 浏览可用工具列表
5. 为需要的工具设置权限
6. 保存更改

### 工具权限级别

每个工具可以设置不同的权限级别：

| 权限 | 描述 | 适用场景 |
|------|------|---------|
| **禁用** | 完全不允许使用 | 安全敏感环境 |
| **只读** | 只能读取，不能修改 | 查看信息 |
| **读写** | 可以读取和修改 | 常规操作 |
| **完全访问** | 无限制使用 | 受信任的环境 |

## 工具使用流程

当智能体使用工具时，会经历以下步骤：

1. **需求分析**：智能体理解任务需求，判断是否需要使用工具
2. **工具选择**：选择合适的工具来完成任务
3. **参数准备**：准备工具调用所需的参数
4. **权限检查**：检查智能体是否有使用该工具的权限
5. **参数校验**：校验参数的合法性和安全性
6. **工具执行**：执行工具的核心逻辑
7. **结果处理**：处理工具执行结果
8. **日志记录**：记录工具调用日志

## 创建自定义工具

高级用户可以创建自己的自定义工具。

### 工具定义结构

一个典型的工具定义包括：

```toml
[tool]
name = "天气查询"
description = "查询指定城市的天气信息"
version = "1.0.0"
category = "external"

[tool.input]
schema = '''
{
  "type": "object",
  "properties": {
    "city": {
      "type": "string",
      "description": "城市名称"
    },
    "units": {
      "type": "string",
      "enum": ["metric", "imperial"],
      "default": "metric"
    }
  },
  "required": ["city"]
}
'''

[tool.output]
schema = '''
{
  "type": "object",
  "properties": {
    "temperature": { "type": "number" },
    "description": { "type": "string" },
    "humidity": { "type": "number" }
  }
}
'''

[tool.security]
required_permissions = ["network"]
rate_limit = { requests = 100, per_hour = 1 }
```

### 实现步骤

1. **定义工具**：创建工具配置文件，描述工具的输入输出
2. **实现逻辑**：编写工具的核心执行逻辑
3. **注册工具**：将工具注册到工具管理器
4. **配置权限**：设置工具的安全要求
5. **测试验证**：测试工具的功能和安全性

## 工具使用安全

### 安全最佳实践

1. **最小权限原则**：只授予必要的权限
2. **沙箱环境**：在受限环境中运行工具
3. **参数验证**：严格验证所有输入参数
4. **审计日志**：记录所有工具调用
5. **定期审查**：定期检查工具使用情况

### 敏感操作提示

对于高风险操作，系统会：
- 显示明确的警告信息
- 要求用户确认
- 记录详细的审计日志
- 提供回滚选项

## 工具使用技巧

### 1. 合理组合工具

不同工具可以组合使用：
- 先用文件工具读取代码
- 再用 Shell 工具运行测试
- 最后用文件工具保存结果

### 2. 设置适当的权限

根据使用场景选择权限：
- 日常使用：只读或读写
- 自动化任务：完全访问
- 演示环境：禁用敏感工具

### 3. 监控和审查

定期检查工具使用：
- 查看工具调用日志
- 关注异常行为
- 及时调整权限

### 4. 从简单开始

先使用内置工具：
- 熟悉工具的功能和限制
- 理解工具的工作原理
- 再考虑创建自定义工具

## 常见问题

### Q: 工具和技能有什么区别？

A: 工具是智能体的外在扩展（"能调用什么"），技能是内在能力（"会做什么"）。技能可以使用工具来完成任务。

### Q: 使用工具会有安全风险吗？

A: 如果配置不当，可能存在风险。请遵循安全最佳实践，只授予必要的权限，并定期审查工具使用。

### Q: 可以限制工具的使用范围吗？

A: 可以！您可以设置文件访问路径白名单、网络访问域名白名单等限制。

### Q: 工具调用失败怎么办？

A: 检查工具日志，查看错误信息。常见原因包括权限不足、参数错误、网络问题等。

### Q: 可以为不同智能体配置不同的工具权限吗？

A: 可以！每个智能体都有独立的工具权限配置。
